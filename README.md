## 📌 About The Project

**Krishna Properties** is a responsive real estate website designed to make property searching simple and convenient.

Users can explore properties available for purchase or rent, apply filters, view property details, browse photos, and save their favourite listings.

The project focuses on a clean interface, easy navigation, and practical functionality using frontend technologies.

## ✨ Key Features

- 🏠 **Property Listings** – Browse properties for sale and rent.
- 🔍 **Smart Search** – Search properties by location.
- 🎯 **Advanced Filters** – Filter by price, property type, bedrooms, and bathrooms.
- ↕️ **Sorting Options** – Sort properties by price and listing date.
- 🖼️ **Photo Gallery** – Explore property images.
- ❤️ **Favourites** – Save and manage favourite properties.
- 👤 **User Authentication UI** – Login and registration interface.
- 🔐 **Admin Panel** – Add, manage, and delete property listings.
- 📸 **Photo Upload** – Upload multiple property images.
- 🌙 **Dark Mode** – Switch between light and dark themes.
- 📱 **Responsive Design** – Works across desktop and mobile screens.

## 💾 Data Storage

The project uses browser **LocalStorage** for demo user information, favourite properties, and property listings.

Currently, it is a frontend-only project without a backend server or database.
