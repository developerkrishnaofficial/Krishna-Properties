Krishna Properties – Buy & Rent

A responsive real estate property listing website built using HTML, CSS, and JavaScript.

🚀 Features

Home page with property search

Buy and Rent property sections

Search properties by location

Filter by property type and price range

Filter by bedrooms and bathrooms

Sort properties by price and listing date

Property details popup

Photo gallery

User login and registration interface

Add and manage properties through Admin Panel

Upload multiple property photos

Add properties to favourites

Dark mode support

Responsive design for desktop and mobile devices

🛠️ Technologies Used

HTML5

CSS3

JavaScript

Tailwind CSS (CDN)

Browser LocalStorage

▶️ How to Run

Download or clone this repository.

Extract the project folder.

Open the folder in Visual Studio Code.

Install the Live Server extension.

Right-click index.html.

Select Open with Live Server.

You can also open index.html directly in your browser.

Note: Internet access is required for loading Tailwind CSS from its CDN.

💾 Data Storage

This project uses browser LocalStorage to store demo user accounts, favourites, and property listings.

It does not currently use a backend server or database. Data is stored locally in the browser.

🎯 Project Objective

The objective of this project is to provide a simple and user-friendly platform where people can explore residential properties, compare listings, view property photos, and manage property information.
